# 🎲 骰仔怪獸棋 v2.3 · Monster Dice

3D 路徑召喚對戰——Three.js 驅動，支援**單機打 AI** 同 **PeerJS 網上雙人**。

## 核心玩法

- 🎯 **目標**：沿住自己嘅路徑推進，打死對面嘅 Boss（龍王🐉 / 魔王👹）
- 🏹 **真・立體拋物線彈道（3 秒限時）**：發射向量＝方位角×仰角×力度——
  - **拖曳**＝方位角（360° 任意角度）＋力度（1–6）
  - **滾輪 ±3° / Q 切換**＝仰角 5°–80°：**射程＝力度×sin(2×仰角)**，45° 飛最遠、高角度短打、低角度扁平
  - ⏰ 3 秒內唔彈？骰仔**自動亂彈**！
- 🎱 **彈跳鏈**：落點撞到**任何已有路徑／怪獸／Boss／半場界線／棋盤邊**→ 由撞擊點反射彈開再飛一段拋物線（能量 ×0.55），一鏈彈到停為止——瞄準預覽會畫出成條彈道鏈
- 🎲 **六面全開**：停低後六面攤開成路徑（有空間保證 6 格），方向順住彈射方位角
- 🚶 怪獸**只可以行喺自己路徑網絡**上，每回合行路＋攻擊各一次
- 👥 **30 隻骰怪**五兵種，開局抽 5，每回合補 1（上限 8）；陣亡唔返手
- 🤝 **網上雙人**：開房攞 5 字房間碼 → 朋友輸碼加入（P2P，host 權威同步）

## 五個兵種

| 兵種 | 例子 | 特性 |
|---|---|---|
| 🟠 近攻 | ⚔️劍士 🗡️刺客 🐺狼騎兵 | 高攻近戰，刺客/狼騎行 3 格 |
| 🟡 遠攻 | 🏹弓箭手 🧨炮手 ❄️冰巫 | 射程 2–3，隔空打 |
| 🔵 防守 | 🛡️盾衛 🐢龜甲衛 🏰城牆兵 | 血 22–30，被動**堅甲：受傷 −2** |
| 🟢 補給 | 💚牧師 ☀️日祭司 🌸花仙子 | 動作=**補友軍血**（射程內，補到 Boss 都得） |
| 🟣 輔助 | 🎺號角手 🚩旗手 🎵詩人 | 被動光環**鼓舞：隔籬友軍攻擊 +2** |

Boss（龍王🐉/魔王👹）：❤️60 ⚔️6，唔可以移動，可以打隔籬。

## 玩法流程

1. **擲骰階段（3 秒限時）**：撳骰仔卡 → 倒數開始 → 撳住自己半場空格拖曳（箭嘴＋落點預覽＋高拋預覽曲線）→ 滾輪/Q 調彈道 → 放手彈射；ESC／短撳取消
2. **行動階段**：每隻自己怪獸可以行路一次（只可行自己路徑）＋攻擊/補血一次
3. 撳自己怪獸 → **綠格**移動 · **紅圈**敵人攻擊 · 補給兵**綠圈**友軍補血 · 撳自己完成行動
4. **結束回合** → 對面行（AI 或者網上對手）
5. 打死對面 Boss 就贏

## 開始

```bash
cd monster-dice
npx http-server -p 8140
# 開 http://localhost:8140/monster-dice/
```

或者直接 double-click `index.html`（要上網載入 Three.js + PeerJS CDN）。

### 網上對戰

1. 一方撳「🌐 開網上房間」→ 攞到 5 字房間碼
2. 對方撳「🔗 加入房間」→ 輸入碼 → 連線
3. 開房嗰方做龍王（下方），加入嗰方做魔王（上方，鏡頭自動翻轉）
4. 依家經 PeerJS 公共伺服器配對，數據直接 P2P 傳，唔經我哋任何 server
